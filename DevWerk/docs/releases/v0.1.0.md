# DevWerk v0.1.0

DevWerk v0.1.0 provides a Project Conversation Agent that can discuss requirements, create and revise a Kanban Workflow through internal tools, create Tasks, and coordinate their execution. Workflow Columns run one agent or a deterministic capability sequence. Directed transitions, feedback, Worker Sessions, scoped memory, and passive Mailbox notifications support long-running delivery.

The repository includes reusable Loop bundles, the browser workbench, Python service, runtime tests, and an IntelliJ integration source tree. See the [repository guide](../../../README.md), [service guide](../../README.md), and [document map](../README.md).
