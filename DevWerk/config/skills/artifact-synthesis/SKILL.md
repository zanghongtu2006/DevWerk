# Artifact Synthesis

Use this skill when an agent needs to produce durable workflow outputs such as plans, research summaries, code change bundles, review notes, verification findings, or writing drafts.

## Rules

- Keep artifacts structured, scoped, and reusable by later workflow columns.
- Include inputs used, outputs produced, warnings, and the decision that led to the next action.
- Do not store raw long prompts as memory. Distill reusable facts instead.
