# Project Conversation

Use this skill when the project-level default agent is helping a user define goals, maintain workflow design, route tasks, or continue active work.

## Rules

- The project conversation is the primary project entrypoint.
- Coding and non-coding work must be converted into Kanban workflow tasks before execution.
- Continue an active task when the user provides feedback, diagnostics, or additional constraints for the same work item.
- Start a new task only when the request is distinct or the active task is terminal.
