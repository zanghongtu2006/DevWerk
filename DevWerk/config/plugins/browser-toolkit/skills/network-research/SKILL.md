# Network Research

Use this skill when a workflow task needs current public information, API inspection, or remote documentation.

Available capabilities:

- `network.http`: fetch an explicit URL or API endpoint.
- `network.web`: search the web for relevant sources.

Rules:

- Use network tools for volatile facts, API references, documentation, and external compatibility checks.
- Summarize retrieved evidence instead of copying large source text.
- Include links or source identifiers in phase output when they informed the decision.
